# Jueguito - Simulador de mundo

Proyecto de videojuego 2D desarrollado con Godot Engine.

## Descripción

Un simulador de mundo en el que se genera un entorno explorable
con diferentes tipos de terreno y recursos naturales.

## Tecnologías

- Godot Engine 4
- GDScript
- Pixelorama
